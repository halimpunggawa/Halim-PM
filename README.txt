HALIM PROJECT MANAGER

Isi paket:
- index.html: aplikasi prototipe
- manifest.webmanifest: metadata instalasi PWA
- sw.js: cache dasar agar halaman dapat dibuka kembali saat offline

Cara mencoba:
1. Ekstrak ZIP.
2. Buka index.html di browser untuk mencoba prototipe.
3. Data teks dan foto disimpan di penyimpanan browser pada perangkat tersebut.
4. Gunakan menu Lainnya > Ekspor JSON untuk membuat cadangan.

Untuk memasang sebagai aplikasi PWA di iPhone:
1. Unggah seluruh isi folder ke hosting HTTPS.
2. Buka alamat situs tersebut di Safari pada iPhone.
3. Tekan tombol Bagikan, lalu pilih Tambahkan ke Layar Utama.

Catatan:
Ini prototipe lokal satu pengguna. Belum ada sinkronisasi cloud, login, pembagian akses tim, atau server database. Jangan jadikan satu-satunya tempat menyimpan dokumen proyek penting. Ekspor cadangan secara berkala.
